ExpenseBot (AI Receipt & Expense Tracker)

Tech Stack: React, Flask, SQLAlchemy, Claude API
Date: May 2026 – July 2026

Overview

Built a full-stack expense-tracking app with a Flask/SQLAlchemy backend and a React frontend, secured with JWT authentication.

Key Features

  • AI-Powered Data Extraction: Integrated Google Cloud Vision OCR and Claude API to automatically extract receipt data.
  • Smart Categorization: Generated confidence-scored expense categories automatically using Claude.
  • Full-Stack Architecture: Developed a robust REST API with Flask and a dynamic, responsive user interface with React.
